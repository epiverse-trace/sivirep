# Eliminar columnas erróneas de los datos del evento o enfermedad

Función que elimina las columnas erróneas de los datos del evento o
enfermedad al importarlos desde el API del SIVIGILA.

## Usage

``` r
remove_cols(data_event)
```

## Arguments

- data_event:

  Un \`data.frame\` que contiene los datos de una enfermedad o evento.

## Value

Un \`data.frame\` con las columnas correctas de los datos del evento o
enfermedad.
